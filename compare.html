What Auditly does not do

Auditly cannot change another app's permissions by itself, because Android does not allow it; Fix it opens the right settings page, or Power mode does it with Shizuku. It is not on Google Play, so it does not update itself.

Where Permission Pilot does more

Permission Pilot shows each app's SharedUserID status, is open source, and installs and updates from Google Play and F-Droid.

If something here is out of date

Apps change. If a row is no longer right, open an issue on GitHub and it will be corrected.
